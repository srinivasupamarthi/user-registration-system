
# User Registration & Data Management System

## Project Overview

The User Registration & Data Management System is a web application that allows users to enter their personal information through a registration form.

The application collects the following details:

- Full Name
- Phone Number
- Email Address
- Location

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- User registration form
- Responsive design for mobile and desktop screens
- Full Name validation
- Phone Number validation
- Email Address validation
- Location validation
- Success message after successful registration
- Automatically clears the form after successful registration

## How to Run the Project

1. Download or clone the project.
2. Open the project folder.
3. Open the frontend folder.
4. Double-click index.html.
5. The registration form will open in your browser.
